# INBOX

Brain-dump of tasks. Light triage, don't over-polish.

Format: `⌛time` (block length) `📅deadline` `⏳when` (scheduled day) `#project`. `#top` = pull this into the important banner. `#scheduled` = already has a calendar entry, don't duplicate it.

To set `⏳`, don't type the emoji by hand — type `/today`, `/tomorrow`, or `/DD-MM-YYYY` anywhere in the task text (Life OS Hub's Inbox tab or the quick-capture input). It crystallizes into a real `⏳ YYYY-MM-DD` on the next render, and a later date command always overwrites the old date. `⌛` and `📅` are still typed as the emoji itself.
